# Voltz — Aprender Eletricidade

Plataforma visual e gamificada, em português de Portugal, para aprender fundamentos de eletricidade e segurança elétrica.

O site inclui um manual de iniciação, 5 categorias, 50 níveis, aulas visuais, desafios aleatórios e progresso guardado no navegador.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Publicação

Cada atualização da branch `main` é publicada automaticamente no GitHub Pages.
